# invoice-to-xlsx

สกัดข้อมูลจาก **ใบรับสินค้า (PDF)** ที่ได้รับจากร้านที่ฝากขายสินค้า แล้วสร้างไฟล์ `.xlsx` ครั้งเดียว
ได้ทั้ง **ใบวางบิล** และ **สำเนาใบส่งของ** (อย่างละ 2 ชุด: ต้นฉบับ/สำเนา) พร้อมพิมพ์ A4 ไม่ต้องเขียนมือ

## ผลลัพธ์ในไฟล์ .xlsx

| ชีต | เนื้อหา |
|---|---|
| `ใบวางบิล-<รหัสผู้ขาย>-ต้นฉบับ` / `-สำเนา` | ตารางสรุปทุกใบ: วันที่รับ, สาขา, เลขที่ใบรับสินค้า, อ้างอิงใบสั่งซื้อ, ใบแจ้งหนี้อ้างอิง, จำนวนเงิน + ผลรวม (สูตร SUM) |
| `ใบส่งของ-ต้นฉบับ` / `-สำเนา` | ใบส่งของใบละ 1 หน้า A4: ข้อมูลผู้ส่ง, ชื่อบริษัท/สาขา/ที่อยู่, ตารางรายการ (รหัสสินค้า, จำนวน, หน่วย, ราคา/หน่วย, จำนวนเงิน), ยอดรวมเป็นตัวเลขและตัวหนังสือไทย, ช่องลายเซ็น |
| `รายการสินค้า` | ทุกบรรทัดสินค้า พร้อมคอลัมน์ตรวจยอด (แถวแดง = ยอดสุทธิไม่ตรงกับผลรวมรายการ ให้ตรวจด้วยตา) |

## วิธีทำงาน

1. อ่านคำพร้อมตำแหน่ง (x, y) จาก text layer ของ PDF ด้วย **PyMuPDF** แล้วแยกฟิลด์ตามพิกัด (แม่นยำกว่า OCR)
2. ถ้า PDF เป็นภาพสแกนที่ไม่มี text จะใช้ **Tesseract OCR** (ไทย+อังกฤษ) เป็นทางเลือกสำรอง (ยังไม่ได้ทดสอบกับไฟล์สแกนจริง)
3. ใบรับสินค้าเดียวกันที่ยาวหลายหน้าจะถูกรวมเป็นใบเดียว
4. ตรวจว่าผลรวมรายการเท่ากับยอดสุทธิทุกใบ แล้วสร้าง `.xlsx` ด้วย **openpyxl**

## ติดตั้ง

ต้องมี Python 3.12+ (และ Tesseract OCR พร้อมภาษา `tha` ถ้าจะใช้ OCR สำรอง)

```bash
pip install -r requirements.txt
```

## ตั้งค่าครั้งแรก (ไฟล์เหล่านี้ไม่ขึ้น git)

1. **`config.json`** ข้อมูลผู้ส่งของ: ก๊อปจาก `config.example.json` แล้วแก้

   | คีย์ | ความหมาย |
   |---|---|
   | `sender_name` | ชื่อผู้ส่งของ (หัวใบส่งของ) |
   | `sender_address` | ที่อยู่ผู้ส่งของ |
   | `sender_tax_id` | เลขประจำตัวผู้เสียภาษีอากร |
   | `deliverer_name` | ชื่อที่พิมพ์ในช่อง "ผู้ส่งสินค้า" |
   | `customer_company` | ชื่อบริษัทที่ส่งสินค้าให้ |

2. **`branches.csv`** ชื่อสาขาและที่อยู่ (คอลัมน์ `รหัสคลัง,ชื่อสาขา,ที่อยู่`) ดูรูปแบบจาก `branches.example.csv`
   ถ้าเจอรหัสคลังใหม่ใน PDF สคริปต์จะเพิ่มแถวให้ใน `branches.csv` เอง เหลือแค่เติมที่อยู่

## วิธีใช้

### แบบหน้าต่างโปรแกรม (แนะนำ)

ธีม Dark สไตล์ Quantix (customtkinter): แถบเมนูซ้าย, การ์ดสรุป, ตารางตรวจรายการ

```bash
python app_gui.py          # หรือดับเบิลคลิก InvoiceToXlsx.exe ถ้า build แล้ว
```

1. หน้า **สกัดเอกสาร** กด "เลือกไฟล์ PDF…" แล้วดูการ์ดสรุป (จำนวนใบ, ยอดรวม, ต้องตรวจ) และตารางตรวจรายการ (แถวแดง = ยอดไม่ตรง, แถวเหลือง = สาขายังไม่มีที่อยู่)
2. กด "สร้างไฟล์ .xlsx…" หรือ **"สร้าง PDF พร้อมพิมพ์…"** (ได้ PDF 2 ไฟล์: ใบวางบิล และ ใบส่งของ แบ่งหน้า A4 ตายตัวใบละ 1 หน้า ต้นฉบับ+สำเนา ไม่ต้องใช้ Excel/Google Sheets) ถ้ามีสาขาที่ไม่มีที่อยู่ โปรแกรมจะเตือนก่อนสร้าง
3. หน้า **สาขา** แก้ชื่อ/ที่อยู่สาขา (บันทึกลง `branches.csv`) และหน้า **ตั้งค่า** แก้ข้อมูลผู้ส่งของ (บันทึกลง `config.json`)

### แบบบรรทัดคำสั่ง

```bash
python invoice_to_xlsx.py "ไฟล์.pdf" -o "ผลลัพธ์.xlsx"
```

ถ้าไม่ใส่ `-o` จะได้ไฟล์ชื่อเดียวกับ PDF นามสกุล `.xlsx` สคริปต์จะแจ้งจำนวนใบที่อ่านได้ ยอดรวม และรายการที่ยอดไม่ตรง

> ถ้าเขียนไฟล์ไม่ได้ (`Permission denied`) แปลว่าไฟล์ผลลัพธ์เปิดค้างอยู่ใน Excel ให้ปิดก่อนหรือเปลี่ยนชื่อ `-o`

## ฐานข้อมูลและ Dashboard

- กด **"บันทึกเข้าฐานข้อมูล"** ที่หน้าสกัดเอกสาร เก็บใบรับสินค้าลง SQLite (`invoices.db`) กันซ้ำด้วยเลขที่ใบรับสินค้า นำเข้าไฟล์เดิมซ้ำได้ ยอดไม่เบิ้ล
- หน้า **Dashboard**: รายได้รวม/จำนวนใบ/เฉลี่ยต่อใบ, กราฟรายเดือน, รายได้ตามสาขา, ตารางสินค้า กรองรายเดือนได้ และ **ส่งออก .xlsx / PDF จากฐานข้อมูล** ตามเดือนโดยไม่ต้องเปิด PDF ซ้ำ
- ไฟล์ฐานข้อมูลอยู่ที่ `%LOCALAPPDATA%\InvoiceToXlsx\invoices.db` (นอก OneDrive กันไฟล์เสียจากการซิงก์) และมีสำเนาสำรองที่ `backup/` ข้างโปรแกรมหลังบันทึกทุกครั้ง (เก็บล่าสุด 15 ไฟล์)
- ยอดเงินเก็บเป็นสตางค์ (จำนวนเต็ม) วันที่เก็บเป็น ISO ค.ศ. แสดงเป็น พ.ศ. ในหน้าจอ
- ชื่อ/ที่อยู่สาขายังเก็บใน `branches.csv` เหมือนเดิม

## หมายเหตุเรื่องการพิมพ์

- ถ้าไม่มี Excel อย่าพิมพ์จาก Google Sheets (ไม่ทำตามการขึ้นหน้าใหม่ทุกใบ) ให้ใช้ปุ่ม **สร้าง PDF** แทน
- สร้าง PDF โดยพิมพ์ HTML ผ่าน Microsoft Edge แบบ headless (`pdf_export.py`) จึงต้องมี Edge หรือ Chrome ในเครื่อง (Windows มี Edge มาให้อยู่แล้ว)

## ข้อมูลที่ไม่ขึ้น git (ดู `.gitignore`)

`config.json`, `branches.csv`, `*.pdf`, `*.xlsx`, `*.db`, `backup/` เพราะมีข้อมูลส่วนตัวและข้อมูลร้านค้า
**ควร backup สองไฟล์แรกแยกต่างหาก** (เช่น OneDrive) เพราะไม่อยู่ใน repo

## ข้อจำกัดที่ทราบ

- รหัสสินค้าที่เจอแล้ว: 02020411, 02020876 (อ่านจากข้อมูลจริง ไม่มี lookup)
- พิกัดคอลัมน์ผูกกับ layout ใบรับสินค้าของ บริษัท สุวรรณชาด จำกัด ถ้าร้านอื่น/ฟอร์มใหม่ต้องปรับค่า `COLS` และพิกัดใน `parse_page`
- วรรณยุกต์ไทยใน PDF ต้นฉบับ map เพี้ยน แก้ด้วย `fix_thai`; ชื่อสาขายาวที่ถูกตัดใน PDF ให้แก้ใน `branches.csv`
- ฟอนต์ในไฟล์ Excel คือ Tahoma

## สร้างไฟล์ .exe

```bash
pip install pyinstaller
pyinstaller --noconfirm --onefile --windowed --name InvoiceToXlsx --paths . --collect-all customtkinter app_gui.py
```

ได้ไฟล์ `dist/InvoiceToXlsx.exe` ให้วาง `config.json` และ `branches.csv` ไว้โฟลเดอร์เดียวกับ `.exe`
(`dist/` ไม่ขึ้น git ควรเก็บ .exe ไว้ที่ OneDrive หรือ GitHub Releases)

## ยังไม่ได้ทดสอบ

- PDF ที่เป็นภาพสแกน (OCR สำรอง)
- ใบรับสินค้าที่ยาวเกิน 1 หน้า และใบที่มีรายการเกิน 16 บรรทัด
